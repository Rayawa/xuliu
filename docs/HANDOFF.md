## 2. 定位、功能与架构

- 个人学习与生活工作台：今日安排、任务/事项、课内和课外学习、课表导入、笔记和附件、专注计时、习惯/提醒、个人记账、AI 助手。
- 技术栈（当前锁定源码）：Next.js 16.3.1 App Router、React 19.2.8、TypeScript 5.9.3、Zod 4；Node.js ≥22.13。使用现有锁文件，未经需求不要顺带升级。
- 页面主要在 `app/DashboardClient.tsx`，其他模块与纯逻辑放在 `app/`、`lib/`。经典/纸页两套样式可切换，默认纸页，支持页面颜色。
- 云端：Node 路由校验登录和权限；签名 HttpOnly 会话；Upstash Redis 保存空间状态，修订号和原子写入防止覆盖并行修改，保留最近 10 份写入前状态；Vercel 私有 Blob 存附件。
- AI：Vercel AI SDK + OpenAI-compatible 适配器调用 DeepSeek，当前源码固定官方地址及 `deepseek-v4-flash`；写入提案须经过预览/确认与版本校验。它与开发使用的 Codex 客户端是不同服务。
- `/preview` 使用演示数据，刷新会重置，不自动保存到真实云端。课表学习安排由客户端规则生成，不是后台定时器，也不自动读取本机 Obsidian。

## 3. 已完成与必须保留的产品决策

- 任务与事项分开；任务周期（短期/长期）与领域（课内、课外、工作、生活、思考）是不同维度，课程节点属于任务。课外学习有开发、专业学习、摄影、日语，归属选项与学习科目关联。
- 今日模块顺序：**短期任务 → 事项 → 长期任务**。长期任务的今日分支放在短期任务。手动学科作业直接显示；只有自动学习任务按学科独立点击展开，使用轻微分隔，不能把手动作业一起折叠。
- **今日阶段提醒（2026-10-12）**：普通长期任务和长期课程任务标注今日推进时，自动补一项关联短期阶段任务；当天已有短期分支则沿用，重复安排不重复生成。阶段可编辑并独立完成；完成阶段不改父任务的进度、完成状态或截止日期。推迟阶段同步父任务的推进日，调整父任务推进日同步未完成阶段；清空安排或删除生成阶段不会在刷新后重新冒出。取消后再安排会复用未完成阶段，换日推进保留已完成阶段历史、个人内容和记录。
- 保留重点课和近期截止的优先排序，不恢复“先做这一项”标签、每日仅一项、兴趣探索/跳过建议等额外流程；用户要求保持基本结构，不作整体重构。
- `plannedDate` 是计划动手日，`due/dueTime`（课程节点为 `date/time`）是截止/节点日期时间。“今天做”仅改推进日，不提前宣告完成或覆盖 DDL。新短期任务推进日默认今天；新选截止日期时默认时间 `00:00`，不是中午。编辑已有任务时保留原设置。
- 已有：基础编辑弹窗、具体要求及附件、部分进度记录、显式推迟一天、更多菜单内详情、快捷删除、长期父任务候选开关；创建成功不自动跳详情。手动关联学科任务显示在学科任务栏，自动学习节点不显示在该栏。
- **HTML 附件（2026-10-14）**：服务端允许 `text/html`，`.html/.htm` 可上传、下载与页面内预览。预览使用无权限的 sandbox iframe 和限制资源加载的 CSP，显示静态正文及内联样式，不执行附件脚本；原文件完整保留。上传与预览大小上限仍为 50/25 MB，权限与私有存储保护沿用原路径。
- 纸页与经典设计均保留；任务详情按需展开，单行表单回车保存，文本域允许换行；应用内刷新/版本提示服务于 Edge 安装版更新，刷新前保护未保存内容。
