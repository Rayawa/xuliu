## 2. 定位、功能与架构

- 个人学习与生活工作台：今日安排、任务/事项、课内和课外学习、课表导入、笔记和附件、专注计时、习惯/提醒、个人记账、AI 助手。
- 技术栈（当前锁定源码）：Next.js 16.3.1 App Router、React 19.2.8、TypeScript 5.9.3、Zod 4；Node.js ≥22.13。使用现有锁文件，未经需求不要顺带升级。

- 云端：Node 路由校验登录和权限；签名 HttpOnly 会话；Upstash Redis 保存空间状态，修订号和原子写入防止覆盖并行修改，保留最近 10 份写入前状态；Vercel 私有 Blob 存附件。
- AI：Vercel AI SDK + OpenAI-compatible 适配器调用 DeepSeek，当前源码固定官方地址及 `deepseek-v4-flash`；写入提案须经过预览/确认与版本校验。它与开发使用的 Codex 客户端是不同服务。
- `/preview` 使用演示数据，刷新会重置，不自动保存到真实云端。课表学习安排由客户端规则生成，不是后台定时器，也不自动读取本机 Obsidian。

## 3. 已完成与必须保留的产品决策

- 任务与事项分开；任务周期（短期/长期）与领域（课内、课外、工作、生活、思考）是不同维度，课程节点属于任务。课外学习有开发、专业学习、摄影、日语，归属选项与学习科目关联。

- `plannedDate` 是计划动手日，`due/dueTime`（课程节点为 `date/time`）是截止/节点日期时间。“今天做”仅改推进日，不提前宣告完成或覆盖 DDL。新短期任务推进日默认今天；新选截止日期时默认时间 `00:00`，不是中午。编辑已有任务时保留原设置。
