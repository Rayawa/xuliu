# 原生番茄钟、护眼与前台提醒

2026-11-03。按本地source最新决策移植。仅编码和构建，未运行测试、启动计时、播放音频、实际申请通知权限或发送提醒。

## 行为

番茄钟使用独立轮次：1–180分钟，默认25分钟、双音、音量40；支持开始、暂停、继续、重置和再来一轮。存在轮次时锁定时长，声音和音量仍可调整。倒计时结束只更新本轮状态与提示，不追加timeEntries，不修改任务elapsed；旧历史字段完整保留。

眼睛循环手动开始，固定专注30分钟、休息5分钟，自动切换阶段；暂停保留剩余时长，继续重新建立截止点，结束回到闲置。可展开查看轮数和周期。后台返回按绝对截止点追赶，最多追赶1000阶段以限制开销，只对最新阶段提示。

前台生活提醒使用上游ReminderScheduler语义：固定分钟去重，休息间隔按墙钟截止点计算，多个到点项目逐个排队，关闭后重计时，可延迟5分钟。项目增删、停用或改时间会更新运行时钟；预览不修改项目、间隔起点和音效状态。页面提示非模态，可关闭后继续处理后续项目。

## 状态与生命周期

LifeRuntime只在模块内保存轮次、护眼状态、时钟与队列，AppStorage仅发布修订信号。今日卡片、独立番茄钟页、生活卡片和跨页提示共用状态。账号切换先按实际时间结算并暂停旧番茄钟、保留其进程内暂停快照；新账号使用自己的快照。护眼和提示队列在账号变化时重置。进程结束后这些临时状态不保留。

番茄钟设置仍在version6的focusSettings。生活提示音偏好经统一Preferences入口按当前账号/设备保存，打开设置不改值、不发声。读取偏好期间不投递生活提醒，避免默认配置抢先消费到点项目。没有活跃计时或提醒项目时只保留跨日唤醒；后台清除活动计时器和声音，前台按经过时间更新。

提示音是按上游频率及包络生成的三份小型本地WAV：柔和523.25Hz/0.8s、清脆880Hz/0.28s、双音659.25Hz与783.99Hz。原生AVPlayer使用通知音频用途、实例音量，不改系统音量、不访问网络或麦克风。播放器、RawFd和超时由单一所有者串行管理并释放。编译不证明设备已经播放成功或用户能够听到。

## 平台边界与后续

系统通知使用NotificationManager：仅用户主动开启时请求授权，读取状态和打开设置不发送测试通知；测试按钮只在用户点击后发送。普通生活/护眼提示可选投递系统通知，声音和振动通过API23可写的关闭标志抑制，由应用独立控制提示音。通知携带仅打开本应用的WantAgent，采用账号/项目标签去重和取消，账号变化或关闭偏好时只清理本模块拥有的通知。

尚未接入后台代理提醒，不宣称应用关闭后仍会准点提醒。应用暂停时清除计时器，回到前台补算；现有通知代码不能代替后台调度。未真实授权、发送或接收任何通知。
