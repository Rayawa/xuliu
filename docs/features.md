## 数据和安全边界

- 数据对象保留原有 version 6 字段；原生编辑不会主动裁剪未编辑的附加字段。云端服务器仍负责最终 schema 校验。
- 导入仅检查原生可识别的结构及容量，不代替上游完整 Zod 校验；上传失败会显示服务端错误，不会绕过校验。
- 登录、云端写入、附件、AI、一言尚未使用实际账号进行验证；构建成功不证明服务可用。
- 上游仓库的 `data/`、`attachments/` 和恢复归档可能包含个人数据，本次没有复制这些资料到应用。
- 尚无签名配置；当前产物是 unsigned HAP，需要配置本人的签名后才能安装。
