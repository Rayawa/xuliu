# 原生文档粘贴与表格

2026-11-04。只编码和构建；未读取实际剪贴板、运行测试或在设备操作编辑器。

- 整理粘贴使用系统 `PasteButton` 成功事件读取本次文本，不新增广泛剪贴板权限、不轮询。原生扫描器只解释标签结构和文本实体，剥离外部颜色、字体、布局、图片与链接资源，不执行HTML、访问网络或加载WebView。保留段落、编号、项目符号、引文、粗斜体、下划线、删除线和等宽代码。实体映射由HTML5标准表生成，按需加载。原生默认粘贴在可用Span上清理格式；不同应用提供的原生剪贴板格式仍需设备验证。
- 单块整理粘贴替换选区，保留其他内容和样式，校验4000字/格式上限；空白授权失败、空内容或超限不删除选区。文档插入菜单可把长文按段落拆成多个合法新块，原文档不覆盖，合为一次撤销。输入超2MB、HTML标签/嵌套/数量超界时保留旧内容或采用剪贴板纯文本，不截断正文。
- `TableEditor` 按行分批显示，每次只激活一个单元格输入；支持追加行列、删除所选行列、整表TSV输入或系统粘贴。保留空白格、带引号的多行字段；HTML合并布局转普通单元格并提示，多个HTML表格要求明确选择。100行、30列、500字限制在文档合同校验入口统一执行。
- 文档草稿先于父级回写更新，撤销/重做按操作或单元格编辑分组并有界；合法大表仍保留至少一次撤销。文档切换、外部更新或组件退出清理历史与帧回调，异步粘贴在切页/后台时失效，原有附件与历史字段保持原样。
- API依据为本机HarmonyOS SDK的PasteButton、Pasteboard、RichEditor及[官方安全粘贴组件说明](https://github.com/openharmony/docs/blob/master/en/application-dev/security/AccessToken/pastebutton.md)。按钮保留系统无障碍标签，相邻控件提供中文说明，未调用API26独占的安全控件自定义描述方法。

下划线和删除线可同时写入文档数据，但RichEditor当前样式属性单次只绘制一种装饰，双线视觉仍是待办。没有进行运行时、安全组件授权、键盘粘贴或设备布局验证。
