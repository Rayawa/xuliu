# 原生复习池与任务阶段

2026-11-03。以下是代码与构建覆盖，没有运行测试、设备交互、迁移真实个人数据或写入真实云端。

## 复习池

`ReviewPage` 按课程分组、按章节折叠并惰性显示行。新增可选已有课程或自填，填写章节和备注，不隐式建立普通任务或选择今天。`ReviewDetailPage` 分开保存名称、备注和小任务标题；每次按编号读取最新工作台，只修改对应字段。名称、备注和小任务标题核对编辑开始时的基线；同时变化时保留输入并显示冲突，不用失焦时的旧整条记录覆盖完成状态或安排。重复保存相同结果可重试本机磁盘写入。

章节与小任务各自维护今日选择及完成日期；取消章节今天不取消小任务，完成小任务不自动完成章节。未选大章节而仅选小任务时，今日页只提供相应小任务勾选。池内完成的小任务即使随后取消选择，仍按明确完成日期计入当日摘要；没有日期的旧完成项不猜测为今天。

删除章节或小任务保留一份当前页撤销快照和原下标。恢复时重新检查容量、同编号/同章节冲突及来源占用，不覆盖较新的现有项目；保留小任务的原完成和选择日期。删除章节只移除池条目，将来源去重加入移除标记，原任务、节点、正文、附件、日志与用时仍在原集合。恢复后移除相应标记。

`ReviewSources` 可只读展开来源正文、要求、成果、附件、进度及用时历史；正文和来源分批显示。归集对任务/事项分别保留作用域，排除正式作业与模糊标题，并附上可明确关联的非正式自动阶段，避免阶段中个人资料被隐藏后不可访问。来源在总览、今日/临期、日历和专注候选中抑制；不是从文件中物理删除。

统一version6校验覆盖500章节、每章50小任务/2000来源、最多30000移除标记；检查编号、日期、完成/进度一致性，以及全池和移除标记之间的来源唯一性。旧进度保留，复习UI无进度滑条。

## 任务阶段

`TaskStages` 对照 `source/lib/task-stages.ts`，由统一 `saveWorkspace` 处理普通编辑：

- 取消关联阶段今天会同步取消尚未进入续做流程的长期父任务；重新选择阶段时同步父级计划。
- 自动阶段跟随父级取消/重选及改期；阶段独立改期或删除时反向更新原父级计划，防止刚删除又自动生成。
- 已完成阶段历史保留；手动任务不被当成可重写的自动阶段。复习来源及其派生阶段不参与生成或同步。
- 当天已存在关联单次安排时不重复生成；优先复用未安排的自动阶段。
- `progressedDates` 已进入续做流程时不再创建额外阶段。今日推进只保存当天推进记录和下次继续日期，不改截止或直接完成任务。原生日期选择页允许修改下次继续日期。
- 普通编辑在未完成→完成时写当天完成日期；重新打开清除完成日期。整库导入/云端替换关闭与旧本机记录的比较推导，避免拿两个空间的历史交叉更新；只基于新快照补全其当天缺少的阶段。

今日可见性、默认推进日及快捷推迟按本地 `source/lib/task-progress.ts` 与 DashboardClient 的现行分支处理。已有长期任务数字进度及日志继续保留；课程、学习和研究不再显示通用进度条，未编辑的历史字段保留。
