# 序流

序流是一套面向个人的工作、学习与生活流管理工具。它把长期结构、今日行动、专注计时和每日复盘串成一个连续系统。

## 当前功能

- 今日任务确认、完成和临时添加
- 日历、截止日期、考试与重要节点
- 课内学习、课外学习、工作研究、灵感、工具集和生活记录
- 自由文件夹与页面，支持标题、清单、图片、表格和链接
- 番茄钟、正向计时、手动补记与每 20 分钟休息提醒
- 睡眠和运动提醒，支持完成、跳过和延迟 5 分钟
- 每日随记、系统汇总和每日复盘
- 本机自动保存、图片记录和 JSON 数据导出
- 桌面与手机响应式界面，可作为 PWA 安装

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可使用。未连接云端数据库时，数据会保存在当前浏览器。

## 数据与部署

当前版本优先保证网页端可用，使用浏览器本机存储保存数据，并提供 JSON 备份导出。项目采用标准 Next.js 结构，可部署到 Vercel。

账号登录、电脑与手机云同步将在后续接入数据库与身份认证后启用。
